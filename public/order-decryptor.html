Order Decryptor

This file decrypts your order details on your own computer. It makes no network requests, loads nothing from the internet and stores nothing. Close this tab when you are done.

  1. Save this file and open the saved copy from your computer.
  2. Check that its SHA-256 checksum matches the one published on the orders page.
  3. Disconnect from the internet if you want an extra guarantee.
  4. Load the encrypted order file you downloaded from the orders page.
  5. Enter the private key of the wallet that placed the order.
